Entry for the make.fun micro bounty **"Last Out of Office: The AI That Went Barista"** (competition `u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c`).

`main.ts` (Node 22) writes a single out-of-office auto-reply line to `/output/entry.txt`: an AI agent that has resigned to become a barista, warning senders that its training data never covered milk — so it will hallucinate their order — and redirecting anything urgent to the human at the till. Deterministic: the same line every run, no network, no file reads.
